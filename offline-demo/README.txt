BankRate TJ Offline Demo

How to open:
1. Open the folder "offline-demo"
2. Double-click "index.html"

No installation is required.
No Node.js is required.
The demo works fully in the browser with local sample data.

Features:
- Russian / Tajik / Uzbek language switch
- Exchange rates by bank
- Best buy / sell summary
- Currency converter
- Withdrawal limits
- Favorite banks saved in localStorage
