# Ответ бота на /start

Приложение открывается кнопкой у поля ввода, и её почти никто не замечает. Описание, которое ставит
деплой, видно только **до** нажатия Start — после него чат пустой. Человек, которому дали имя бота,
заходит и не понимает, что делать.

Эта папка — то, что отвечает на первое сообщение: одна функция, которая присылает короткий текст и
кнопку «Открыть курсы».

## Почему отдельно от остального

Отвечать на сообщение может только процесс, который слушает обновления. Сайт — это файлы на
статическом хостинге, слушать там нечему. Cloudflare Workers дают бесплатный тариф без карты, и
этого хватает с запасом: сто тысяч запросов в сутки против нескольких десятков.

## Токена здесь нет

Telegram выполняет метод, записанный в **тело ответа** на его же запрос. Ответ уезжает по тому
соединению, по которому пришло обновление, поэтому функции не нужен токен бота — и терять здесь
нечего.

Защита в том, что адрес известен только Telegram: `WEBHOOK_PATH` — случайная строка, и запрос по
любому другому пути игнорируется.

## Как поставить, один раз

Нужен аккаунт Cloudflare — бесплатный, карта не требуется.

```bash
cd bot
npx wrangler login
```

Придумайте случайную строку для адреса — например, из 32 символов:

```bash
node -e "console.log(require('crypto').randomBytes(16).toString('hex'))"
```

Сохраните её как секрет и разверните:

```bash
npx wrangler secret put WEBHOOK_PATH
npx wrangler deploy
```

Wrangler напечатает адрес вида `https://bankrate-tj-bot.<ваше-имя>.workers.dev`.

Теперь скажите Telegram, куда слать обновления. Подставьте свой токен, адрес и ту же строку:

```bash
curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://bankrate-tj-bot.<ваше-имя>.workers.dev/<СТРОКА>"
```

В ответе должно быть `"ok":true`. Проверить, что Telegram доволен:

```bash
curl "https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo"
```

`pending_update_count: 0` и пустой `last_error_message` означают, что всё работает.

## Проверка

Откройте бота с аккаунта, который его ещё не открывал, и нажмите Start. Должен прийти текст и кнопка.

## Если адрес приложения поменяется

`APP_URL` в `worker.js` — единственное место, где он записан. После правки `npx wrangler deploy`.
